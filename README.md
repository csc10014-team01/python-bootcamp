# Python Bootcamp

## Directory Structure
- `members/<username>/`: Individual homework directories for each team member.
- `shared/`: Shared team code (used starting from W2, W3).
- `tests/`: Standard test suites provided by the instructor.

## Running Tests
```bash
pytest -q python-bootcamp/tests/test_w1.py --member <your_folder_name> --variant <your_variant_num>
```
